Student Grade Calculator

Description
This project is a Python-based student grade calculator.  
It takes student marks, calculates average, assigns grades, and shows statistics.

Features
- Multiple student support
- Grade calculation (A–F)
- Average calculation
- Class statistics (highest, lowest, average)
- Input validation

Concepts Used
- if-elif-else
- loops (for, while)
- lists
- functions
- error handling (try-except)

How to Run
```bash
python grade_calculator.py

Grading System
A: 90–100
B: 80–89
C: 70–79
D: 60–69
F: below 60
